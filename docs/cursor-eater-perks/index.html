Eater Perks

Creating an Eater Perks experience using Cursor

Eater decided they wanted a perks experience like New York Magazine. They wanted their perks to be connected to Eater Awards and have different perks for each cities but the core perk redemption experience would be the same. Because I had already designed the core experience for New York Magazine, I figured we could move quicker using Cursor.

Initial Prototype

To start the project, I worked with product on what specific features we wanted from the New York Magazine experience vs. which features we needed to add:

  1. City Picker - Eater wants different sets of perks for each city instead of a centralized landing page for all perks so I need to give the user the option to select the city they're interested in.
  2. Sign In - For New York Magazine, there was a "sign in" button at the top of the page if you weren't logged in. For Eater, we decided to have a small "sign in" link at the top but if you weren't logged in, the sign in form would appear in a modal when you click "redeem in-store."
  3. Eater Awards branding - This editorial project had specific branding and the perks experience is part of that project. This meant we could use global components but we might need to tweak their styling so the page felt more like a branded landing page, not part of the general site.

Because the rest of the flow had already been tested and finalized for New York Magazine, I moved straight to prototyping for Eater. I built a prototype using global Eater components (buttons, sign in forms, headings, etc) with the new Eater-specific features.

Design Iterations

I sent this prototype for product, engineering and marketing so they would have a general idea of how the page would work. Then, I moved on to updating the visual design for the page to fit with the Eater Awards branding.

The Eater creative director sent me some of the work she'd done for Eater Awards so I could base the perks visual design off of it.
