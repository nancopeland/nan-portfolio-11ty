Eater Perks

Creating an Eater Perks experience using Cursor

Eater decided they wanted a perks experience like New York Magazine. They wanted their perks to be connected to Eater Awards and have different perks for each cities but the core perk redemption experience would be the same. Because I had already designed the core experience for New York Magazine, I figured we could move quicker using Cursor.

[gif of final experience]

To start the project, I worked with product on what specific features we wanted from the NYMag experience vs. which features we needed to add.
