Overtone Design System

A new design system for migrating from Chorus to Wordpress

I managed the migration of Vox, The Verge, Eater and SB Nation to the design system, Overtone, that I built 0-1. The migration was part of a larger project where we migrated these sites from Chorus to Wordpress. This project involved balancing design, product, editorial and engineering needs with good user experience and bespoke brand expression for each site. Design management specifically wanted designers to be able to manage type, spacing and color details without engineering.

Project Goals

I started by speaking with stakeholders from different teams and decided on these goals:

  • Same front-end system
  • Designer-managed tokens
  • Well-designed default layouts
  • Bespoke brand expression
  • System that allows for custom design + engineering work when necessary

Tokens & Theming

The goal was for each site to look good out of the box when it migrated to Wordpress but also allow varying levels of customization, depending on the brand's visual and editorial needs.

To set up a new site, a brand could set 1-2 fonts and 1-2 colors and use default layouts for everything. But, if a brand wanted to spend a lot more time customizing both their branding and tooling, that would also work within the system.

To achieve this, the system uses shared design tokens that are assigned to shared elements between the sites. The tokens have different styles (aka values) so each site can have different fonts, colors, etc. but be on the same system.

Navigation

The navigation has some standardized parts and some customizable parts. The top-of-page nav is customizable in terms of layout but is made up of the same components (logo, category links, hamburger menu button). The menu that pulls out from the hamburger icon has a standardized layout but allows for color and type styling.

Homepage

The homepage is the most customizable layout in the system. It has no default layout but instead is customized for each site with reusable components such as newsletter, most popular and content card pattern components (ex. 3 grid, 5 grid, 6up, etc).
